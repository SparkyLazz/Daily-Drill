### Full solution — lighthouse visibility log (now retired)

**The problem.** Count the nights whose reading is strictly higher than every earlier reading. The first night always counts. Equal does not count. An empty season is `0`.

**The reasoning.** "Strictly higher than every night before it" sounds like it needs all the earlier nights, which is what the brute force does — for each night, scan everything to its left. That is `O(n²)`. But you never need the earlier readings themselves, only the largest one, because a reading beats all of them exactly when it beats the largest. So one number carried forward is enough, and one pass does it.

The only real decision is what that number starts as, and the whole trap lives there:

- `0` is wrong. An all-negative season has records, and every one of them is below `0`, so they all get silently discarded. `[-5, -8, -5, -2]` would return `0` instead of `2`.
- `-1000` is wrong for a subtler reason. It happens to be below every legal reading, so it mostly works — but a season that opens with `-1000` would not count its own first night, because `-1000` is not strictly greater than `-1000`. `[-1000]` would return `0` instead of `1`. A sentinel that sits *at* the boundary instead of below it fails on the boundary.
- `readings[0]` is wrong because it asserts a first night exists.
- **"unset" is right.** It makes no claim about the data at all, so there is nothing for the empty season to contradict.

**Verified code.**

```python
def solve(readings: list[int]) -> int:
    best = None
    records = 0
    for reading in readings:
        if best is None or reading > best:
            best = reading
            records += 1
    return records
```

`best is None` is checked first, so on the very first night the comparison `reading > best` is never evaluated and no `TypeError` can occur. Every later night compares normally. `records` only ever increments, and it starts where the empty answer is.

**Walk-through on Example 2, `[-5, -8, -5, -2]`:**

The four apprentices are **Ayu, Bima, Citra and Dedi**. Each sits on exactly one stool, and no two share a stool.

Each apprentice is working on a single cloth, and each cloth is being dyed in exactly one colour: **indigo, saffron, rust or green**. No two apprentices are working in the same colour.

The workshop owner remembers these six things about that morning, and all six are true:

1. Citra sits nearer the window than Bima, and Citra is not on the stool at the window end.
2. The indigo cloth is on an odd-numbered stool.
3. Dedi sits directly next to the apprentice working in saffron — immediately to that apprentice's left or immediately to their right, with no stool in between.
4. The rust cloth is on stool 4.
5. Ayu is working in neither indigo nor saffron.

**What you must produce.** For each of stools 1, 2, 3 and 4: which apprentice sits there, and which colour that apprentice is working in. Then a **written argument** showing that this is the only assignment of apprentices and colours to stools that satisfies all six facts.
