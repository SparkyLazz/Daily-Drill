**Full solution — the ferry turnstile.**

The question asks for the longest stretch of consecutive minutes that rises strictly from each minute to the next. The key observation is that a stretch ending at minute *i* either extends the stretch ending at minute *i−1* — which happens exactly when `counts[i] > counts[i-1]` — or it cannot extend it at all, in which case the longest stretch ending at *i* is just minute *i* alone, length 1. There is no third case and no choice to make. So a single left-to-right walk that carries the length of the stretch ending at the current minute, plus the best length seen anywhere so far, computes the answer; nothing earlier than the immediately preceding minute can ever matter, because the condition linking minute *i* to a longer stretch involves only minute *i−1*.

That is why no rescanning is needed and why the whole thing is one pass. Verified Python:

```python
def solve(counts: list[int]) -> int:
    best = 0
    run = 0
    prev = None
    for value in counts:
        if prev is not None and value > prev:
            run += 1
        else:
            run = 1
        prev = value
        if run > best:
            best = run
    return best
```

Walk-through on `[2, 5, 9, 3, 4]`:

| value | rises over prev? | run | best |
|---|---|---|---|
| 2 | — (first) | 1 | 1 |
| 5 | yes | 2 | 2 |
| 9 | yes | 3 | 3 |
| 3 | no | 1 | 3 |
| 4 | yes | 2 | 3 |

Answer `3`, the stretch `2, 5, 9`. On `[7, 7, 7]` the comparison is `>`, not `>=`, so equal minutes never extend a run: `run` is reset to 1 at each of the second and third minutes and the answer is `1`. Starting `best` at `0` rather than `1` is what makes the empty list return `0` without a special case — your version needed the explicit `if len(counts) == 0: return 0` guard because you started both counters at 1. Both are correct; the difference is worth noticing, because the pattern of "pick the initial value so that the empty case falls out of the loop for free" removes guard clauses in a lot of problems.

Complexity: one pass, O(n) time, and two integers plus one previous value of extra space regardless of input size — 100,000 minutes in 0.004 s.
