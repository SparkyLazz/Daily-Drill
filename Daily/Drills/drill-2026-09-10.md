### The solution

```python
def puzzle(array):
    boundary = 0
    for i in range(len(array)):
        if array[i] != 0:
            array[boundary], array[i] = array[i], array[boundary]
            boundary += 1
```

**Why it works.** `boundary` marks the first slot that has not yet been filled with a non-zero value. The loop guarantees, at every step, that positions `0 .. boundary-1` hold exactly the non-zero values seen so far, in their original order, and that positions `boundary .. i` hold only zeros. When `array[i]` is non-zero, swapping it into `array[boundary]` extends the first region by one, and whatever was at `boundary` — necessarily a zero, or `i` itself when `boundary == i` — moves out to position `i`, extending the second region. Order among non-zero values is preserved because they are placed into `boundary` in exactly the order they are encountered. When the loop ends, `i` has reached the end, so the first region is every non-zero value in order and the rest is zeros.

**Walk-through on `[0, 1, 0, 3, 12]`:**

| i | array before | array[i] | action | boundary after |
|---|---|---|---|---|
| 0 | `[0,1,0,3,12]` | 0 | skip | 0 |
| 1 | `[0,1,0,3,12]` | 1 | swap 0↔1 → `[1,0,0,3,12]` | 1 |
| 2 | `[1,0,0,3,12]` | 0 | skip | 1 |
| 3 | `[1,0,0,3,12]` | 3 | swap 1↔3 → `[1,3,0,0,12]` | 2 |
| 4 | `[1,3,0,0,12]` | 12 | swap 2↔4 → `[1,3,12,0,0]` | 3 |

The swap-with-yourself case (`boundary == i`, which happens on every element of a list with no zeros) is harmless: the element is written back to where it already was. Your explicit three-line `temp` swap is correct; Python's tuple assignment does the same thing in one line and is the idiom to prefer.
