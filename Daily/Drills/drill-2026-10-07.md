## Today's problem

A lighthouse keeper records one visibility reading at dusk every night of the season, in order, as a list of integers. Readings can be negative: the scale runs from heavy fog at the bottom through to perfectly clear at the top, and zero is an ordinary middling evening, not a floor.

The keeper wants to know how many **record nights** the season contained. A night is a record night if its reading is strictly higher than the reading of every night that came before it in the season. The very first night of the season has no night before it, so it is always a record night. A night that merely equals the best reading so far is not a record night — it has to beat it.

Write `def solve(readings: list[int]) -> int` returning the number of record nights in the season. An empty season has zero record nights.

Constraints:
- `0 <= len(readings) <= 100000`
- `-1000 <= readings[i] <= 1000`
- Do not modify the input list.

Example 1: `readings = [3, 1, 4, 4, 7]` → returns `3`
Example 2: `readings = [-5, -8, -5, -2]` → returns `2`
