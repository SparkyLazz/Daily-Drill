## Today's problem

A hiking club in Lembang keeps a log for each trail it walks. The trail is cut into numbered segments, walked in order, segment 1 first. For each segment the log records the **net change in altitude in metres** over that segment: a positive number means the segment ended higher than it began, a negative number means it ended lower, and zero means it ended at the same height.

The walk begins at the trailhead. Call the trailhead's altitude **0 metres**. The altitude at the end of any segment is 0 plus every recorded change up to and including that segment.

The club wants one number for the trail: **the highest altitude, in metres above the trailhead, that the walkers stood at at the end of any segment.** If they never stood above the trailhead at the end of any segment, the answer is **0**. An empty log — a trail with no segments recorded — also gives **0**.

Write

```
def solve(climbs: list[int]) -> int
```

returning that number. `climbs[i]` is the net altitude change over segment `i + 1`. The function must not change the list it is given.

Constraints:
- `0 <= len(climbs) <= 100000`
- `-1000 <= climbs[i] <= 1000`
- Altitude is measured only at the ends of segments, never part-way through one.
- The answer is never negative: the trailhead is 0 metres and counts as a height the walkers stood at before segment 1.

Example 1:

```
climbs = [3, -1, 4, -6, 2]
solve(climbs) -> 6
```

Example 2:

```
climbs = [-2, -3, 1]
solve(climbs) -> 0
```
