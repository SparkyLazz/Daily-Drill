**Full solution — largest drop between an earlier and a later hourly count.**

Reasoning. The quantity asked for is `max over all i < j of (counts[i] - counts[j])`. Fix the later hour `j` and ask what the best partner is: since `counts[j]` is fixed in that expression, the difference is largest when `counts[i]` is largest, over all `i < j`. So for each position `j` the only fact about the past that matters is the single largest value seen strictly before `j`. That collapses the problem from "examine every pair" to "walk left to right, carrying one number".

Why it works. Scan positions in order, carrying `highest` = the largest count seen so far. At position `j`, `highest - counts[j]` is by construction the best difference among all pairs whose later hour is `j`. Every valid pair has exactly one later hour, so as `j` runs over all positions, every pair is accounted for by exactly one step of the scan; taking the running maximum of those per-position bests therefore gives the global maximum. Updating `highest` with `counts[j]` *before* or *after* computing the difference does not matter, because `counts[j] - counts[j] = 0` can never beat a `best` that starts at `0` — so the degenerate `i == j` pair is harmless. `best` starting at `0` also delivers the "return 0 if no pair gives a positive difference" clause for free, including on the empty list, where the loop body never runs.

```python
def solve(counts: list[int]) -> int:
    best = 0
    highest = 0
    for c in counts:
        if c > highest:
            highest = c
        if highest - c > best:
            best = highest - c
    return best
```

Walk-through on `[8, 3, 9, 4]`:

| c | highest after update | highest - c | best |
|---|---|---|---|
| 8 | 8 | 0 | 0 |
| 3 | 8 | 5 | 5 |
| 9 | 9 | 0 | 5 |
| 4 | 9 | 5 | 5 |

Answer `5`, from the pair (hour 1 → hour 2) — and equally (hour 3 → hour 4). On `[1, 5, 2, 10, 6]` the running highest goes 1, 5, 5, 10, 10 and the differences are 0, 0, 3, 0, 4, so the answer is `4`. One pass, constant extra space, and the list is never touched.
