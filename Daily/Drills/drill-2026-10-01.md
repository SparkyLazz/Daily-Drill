**Full solution — the village weighing station.**

The question is: of all the distinct weights recorded, what is the second largest? One walk through the list is enough, because at any point the only two facts worth carrying are the largest weight seen so far and the largest weight seen so far that is strictly below it. Everything else is irrelevant — a weight that is neither of those two can never become the answer later, since any future weight that beats it would beat it just as easily whether you remembered it or not.

Each new weight `w` falls into exactly one of three situations, and the third is the one that needs care:

1. `w > best` — a new heaviest pumpkin. The old `best` is now the largest weight strictly below the new one, so it becomes `second`, and `w` becomes `best`.
2. `w == best` — a tie with the heaviest. It changes nothing. It is not a runner-up by definition, and it does not displace anything.
3. `w < best` — then `w` is a candidate for the runner-up slot, and it takes it only if it beats what is already there.

Verified Python:

```python
def solve(weights: list[int]) -> int:
    best = -1
    second = -1
    for w in weights:
        if w > best:
            second = best
            best = w
        elif w != best and w > second:
            second = w
    return second
```

Walk-through on `[4, 9, 9, 2, 7]`:

| w | situation | best | second |

| — | start | -1 | -1 |

| 9 | ties best | 9 | 4 |

Answer `7`. On `[6, 6, 6]` the first `6` sets `best`, the other two tie it and are ignored, `second` is never written, and the function returns `-1`.

Now the part worth taking away. `-1` is doing two jobs at once here, and it only gets away with it because the constraints said `0 <= weights[i]`. It is the sentinel meaning "nothing recorded yet" — and it is also the exact value the problem asks you to return when nothing qualifies. Because every legal weight is strictly greater than `-1`, the first real weight always wins the `w > best` comparison, and the empty list, the single-element list and the all-same list all return `-1` without a single guard clause.
