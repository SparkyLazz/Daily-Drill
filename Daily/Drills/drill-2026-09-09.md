# Drill — Wednesday, 2026-09-09

## Problem
You are given a list of whole numbers, which may contain any mix of zeros and non-zero values. Modify that same list so that every zero ends up positioned after every non-zero value. The non-zero values must remain in the same order relative to one another as they were originally. The change must be made to the given list itself rather than by producing a separate list, and nothing is returned.

Example 1
Input: [0, 1, 0, 3, 12]
Output: [1, 3, 12, 0, 0]

Example 2
Input: [4, 0, 0, 5, 0, 7]
Output: [4, 5, 7, 0, 0, 0]
